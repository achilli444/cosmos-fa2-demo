### Mission impact (for a C2 operator)

- **A1 config-overlay RCE.** Any authenticated user may write under `targets_modified/`; target config is ERB-evaluated on load. Impact: an operator-level account (not admin) gets arbitrary Ruby on the cmd/tlm host — command authority over every target in scope, silently, with the malicious config persisting across restarts.
- **A2 `pypi_url` command injection.** The `pypi_url` admin setting is spliced into a backtick shell command at plugin install. Impact: whoever can set one string owns the API container; plugin install is a routine ops action, so the trigger looks like normal maintenance.
- **A3 unauthenticated global logout.** `PUT /openc3-api/users/logout/:user` calls `AuthModel.logout` (`Store.del(SESSIONS_KEY)`) with no `authorization()` check. Impact: one unauthenticated request from anywhere with network reach terminates every operator session at once — denial of command-and-control mid-contact, repeatable on a loop.
- **A4 Script Runner suite injection.** `suite`/`group`/`method` from the client are interpolated into Ruby source and executed. Impact: bypasses the Script Runner approval boundary — code runs that no reviewer approved, from an account that is only allowed to run *approved* procedures.
- **A5 stored XSS via BUTTON.** Button text is `eval()`'d in every operator's browser that opens the screen. Impact: one screen edit turns into command execution in other operators' sessions (their token, their permissions).
- **A6 heap OOB read.** Integer overflow in bit-offset/size checks in the native accessor. Impact: crafted telemetry/packet definitions read out of bounds — crash (loss of telemetry processing) or memory disclosure in the decom/API process.
- **A7 `public_send` bypass.** The JSON-RPC denylist blocks `send`/`__send__` but not `public_send`. Impact: authenticated caller reaches API-object methods the interface never intended to expose; scope of harm depends on reachable methods (advisory: medium).
- **A8 swallowed AuthError.** `rescue Exception` after `authorize(permission: 'admin')` means a non-admin's call proceeds past the check. Impact: authorization failure is logged as a generic error and the write path continues — an audit gap rather than a direct C2 takeover.
